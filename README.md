# Projet React - Boutique
---

## Installation

1. Se placer dans le dossier tp5 :
```
cd tp5
```

2. Installer les modules :
```
npm install
```

## Lancer le projet

Démarrer le serveur de développement :
```
npm run dev-server
```

adresse : http://localhost:9000

## Build

Pour mettre à jour le dossier dist/ :
```
npm run build
```
---

## Fonctionnalités réalisées

- Affichage de la liste des produits en boutique
- Ajout d'un produit au panier
- Gestion des stocks (communications entre boutique/panier)
- Modification de la quantité dans le panier avec les flèches
- Suppression d'un article du panier
- Filtre des produits par nom
- Affichage du poids total et du total commande
